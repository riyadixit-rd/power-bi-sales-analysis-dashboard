# Power BI Sales Analysis Dashboard

An interactive **Sales Analysis Dashboard** built using **Microsoft Power BI** and **MySQL** to analyze sales performance, profitability, product performance, regional performance, and monthly trends.

## 📌 Project Overview

This project transforms sales data stored in MySQL into an interactive Power BI dashboard.

The dashboard provides a quick overview of key business metrics and allows sales performance to be analyzed across different categories, regions, products, and months.

## 🎯 Objectives

- Analyze overall sales and profitability
- Track total sales and total orders
- Calculate average order value
- Monitor overall profit margin
- Compare sales across product categories
- Analyze regional sales performance
- Identify top-performing products
- Understand monthly sales trends

## 💡 Key Insights

- **Laptop** generated the highest sales with ₹2,75,000.
- **Electronics** was the top-performing category with ₹4,29,300 in sales.
- **South** recorded the highest regional sales at ₹1,64,500.
- **February** had the highest monthly sales at ₹1,31,900.
- **Laptop** generated the highest product-level profit of ₹35,000.
- The overall profit margin was **16.39%**.
